### Общая гражданская информация о пациенте

Ф.И.О., дата рождения, телефон, электронная почта, адрес прописки, место работы или учёбы.

Тип: Personal Information

- Источники: Patients file, Data files, Почта
- Методы защиты: Ролевой доступ / Шифрование (диска, почты) / Перемешивание (для аналитики) / Журналирование
- Теги: PII

### Медицинская информация о пациенте

Диагноз, рекомендации, результаты лабораторных и инструментальных исследований

Тип: Personal Health Information

- Источники: Data files, Journal Doctor files, RegistryByDate files
- Методы защиты: Ролевой доступ / Шифрование / Токенизация (для хранения результатов лабораторных исследований) / Перемешивание (для аналитики) / Журналирование
- Теги: PHI

### Финансовая информация компании

Платежи, данные по прибыли, расходам, зарплатам и т.п.

Тип: Financial Confidential Information

- Источники: 1C: Бухгалтерия, KMM
- Методы защиты: Ролевой доступ / Шифрование / Перемешивание (для аналитики) / Маскирование (для разработки 1С) Журналирование
- Теги: FСI

### Информация о материальных ценностях компании

Оборудование, расходные материалы и т.п

Тип: Materials Confidential Information

- Источники: 1C: Бухгалтерия, 1C: Торговля и склад
- Методы защиты: Ролевой доступ / Шифрование / Перемешивание (для аналитики) / Маскирование (для разработки 1С) / Журналирование
- Теги: MСI
